This week we talked about emergent storytelling and basic game physics.

Basic Game Physics

→ Euler method: position + velocity

→ Circle-point collision

→ Grid collision is useful for pixel games

→ Vectors can help calculate movement

→ Sine waves create oscillation

→ Ragdolls are affected by physics

→ Change in velocity = acceleration
